# Дизайн DigiComp HUB

Затверджено власником 2026-11-09 (етап 6). Макети 4 ключових екранів (телефон світлий і темний, комп'ютер):
[полотно «DigiComp HUB — макети»](https://claude.ai/artifact/VU4D9FhnF8KwMxgkSAG1Uv) (приватне, доступ у власника).
Значення кольорів, шрифтів і розмірів — у [`tokens.json`](tokens.json): фронт бере їх звідти, а не з макетів.

## Правила

- **Колір.** Синій (`primary`) лише для головної дії на екрані й активних станів: поточна вкладка, вибраний фільтр, активний сеанс.
  - Зелений, жовтий і червоний — лише для статусів.
  - Кожна пара тексту й фону має контраст не менше 4,5:1 в обох темах; нові кольори додаємо лише з такою самою перевіркою.
- **Теми.** Світла й темна. За замовчуванням береться системна, у профілі можна вибрати вручну.
- **Шрифт.** e-Ukraine для тексту (400, 500, 700), e-Ukraine Head для заголовків (500, 700). Основний текст 16/24.
- **Розміри.** Зона натискання не менше 44 px, кнопки 48 px, головна кнопка екрана («Почати роботу») 56 px.
  - Закруглення: картки 16–20, кнопки й поля 12, мітки повністю круглі.
  - Відступи кратні 4.
- **Навігація.**
  - Телефон: нижня панель з 5 вкладок (Головна, ТЗ, «Скан QR» по центру, Лабораторія, Профіль), решта в меню «Ще».
  - Комп'ютер: бічне меню; розділ «Керування» бачать лише модератори й адмін.
- **Дошка ТЗ.**
  - Телефон: вкладки за статусами з лічильниками.
  - Комп'ютер: 5 колонок (Вільне, В черзі, В роботі, На перевірці, Виконано) з перетягуванням.
- **Рух.** Переходи 150–250 мс, скелетони замість порожніх екранів, оптимістичні оновлення. Із системним «менше руху» — без анімацій.
- **Помилки й порожні стани.** Людський текст за `errorCode` з бекенду і підказка, що робити далі. Ніколи не «Щось пішло не так».
- **Іконки.** Лінійні (stroke 2), без емодзі. Кнопки лише з іконкою мають `aria-label`.
- **Друк.** Журнал обладнання друкується зі сторінки `/api/work-sessions/report` (A4, без інтерфейсу).
